辅导员工作室专栏 | 科学防艾 健康同行——春晖辅导员工作室举办“春晖心航・大学生情感教育系列讲堂”

学生工作部 · 2026-05-08

有些话题不必羞于开口，有些知识必须认真学习。为引导青年学子树立正确健康观念，提升自我保护能力，5月14日晚，由春晖辅导员工作室主办的 “春晖心航・大学生情感教育系列讲堂”第三讲——“聊聊年轻人羞于开口的那些健康事”，在大学城校区教学楼G207温暖开讲，讲座由商学院辅导员王文宇主持。

讲座现场

本次讲座聚焦性健康知识普及与艾滋病预防，特邀广东省性病艾滋病防治协会学校项目部部长姚芷潞主讲，用专业、温暖、易懂的方式，为在场同学带来一堂实用又走心的青春健康必修课。

讲座打破传统说教模式，创新采用论坛剧场形式，让健康科普更有温度、更易接受。活动伊始，学生团队带来性疾病预防主题情景短剧，用沉浸式剧情还原日常场景，搭建轻松沟通的桥梁。现场同学跟随剧情思考、讨论、互动，在真实感与代入感中直面健康话题，不再回避、不再羞涩。

现场互动

随后，姚芷潞老师结合剧情与现实案例，深度剖析常见认知误区与不当行为，用互动讲授的方式，系统科普性健康知识、理性决策原则、艾滋病预防核心要点，同时引导大家学习健康亲密关系的相处之道，干货满满、实用性强。在老师循序渐进的引导下，同学们主动提问、积极交流，大胆解锁健康知识盲区，现场氛围热烈而融洽，真正实现听得进、记得住、用得上。

现场互动

本次专题讲座，旨在填补大学生在艾滋病防治与性健康领域的认知缺失，帮助大家系统掌握专业知识与防护技能，进一步提升自我保护意识与同伴教育能力。科学防艾，不是恐惧与回避，而是认知、尊重、守护—— 懂得保护自己，也懂得尊重他人，用理性与责任守护纯粹而美好的青春时光。

未来，春晖辅导员工作室将持续聚焦学子成长核心需求，推出更多贴合学子实际需求的主题活动，陪伴大家收获积极健康、充实丰盈的大学生活。
