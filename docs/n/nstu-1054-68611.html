石榴同心 启航新程——我校举办2026级新疆籍少数民族生入学教育培训会

学生工作部 · 2026-10-09

2026年是中国共产党建党105周年、长征胜利90周年。值此回望伟大征程、赓续奋斗精神的历史节点，我校立足“十五五”规划开局起步的时代方位，以铸牢中华民族共同体意识为主线，于9月29日下午在大学城校区组织开展2026级少数民族新生入学教育培训。会议由学生工作部副部长侯运男主讲，学生工作部缪冠中主持，学院民族生辅导员代表及全体2026级新疆籍少数民族学生参会。

培训伊始，侯运男副部长作新生入学教育专题培训。他结合今年7月赴新疆开展家访的真切感悟，立足新疆日新月异的发展实际，向在场新生介绍了“十四五”以来新疆的全方位发展成就，以及“十五五”时期新疆战略地位升级、重点领域爆发增长的发展机遇，围绕“筑牢同心向党的家国情怀、练就无惧竞争的过硬本领、坚守自信自强的青春底色”明确三点成长期望，指出同学们既是家乡发展巨变的亲历者与最大受益者，学校核心学科精准匹配新疆未来核心人才需求，勉励大家铸牢中华民族共同体意识，成长为契合发展需要的复合型、国际化高素质人才。侯运男系统阐释学校民族生工作“严、细、爱、实”的工作理念，着重强调校纪校规与校园安全底线，鼓励同学们树立长远规划，在广外的校园里收获成长。

随后进入“石榴课堂”普法宣讲环节，石榴课堂主讲人、法学院2025级本科生热阳古丽作《中华人民共和国民族团结进步促进法》专题解读。她介绍，这部2026年7月1日起施行的基础性法律，以铸牢中华民族共同体意识为主线，阐释共同体理念与“三个有利于”原则。她号召同学们主动学法用法，积极与各民族同学交往交流交融，争做民族团结的践行者和守护者。

区域国别学院2023级本科生祖丽米热结合自身在校经历分享成长经验。她提醒预科新生要重视预科阶段的过渡学习，打牢学业基础；鼓励大家主动把握各类校园实践机会，在实践锻炼中积累经验、拓宽视野，实现全面成长。

商学院2026级学生阿丽米热上台发言。她表示在校期间将深耕专业知识、打磨双语能力，平衡学习与实践，努力成长为具备跨文化沟通能力的复合型人才，不负学校的培养与期待，以实际行动回报国家与社会。

此次入学教育培训会，紧扣“十五五”规划开局的时代脉搏，将“知校、爱校、荣校、强校”教育贯穿全程，不仅帮助新生明晰成长方向、筑牢思想根基，更将个人成长与国家战略、边疆发展深度绑定，以丰富的学习内容与温暖的集体关怀，为同学们的大学之路指引前行方向。未来，学校将持续深耕民族生教育培养工作，扎实铸牢中华民族共同体意识，助力同学们同心共进，在服务国家发展、建设边疆的征程中书写属于自己的青春答卷。
